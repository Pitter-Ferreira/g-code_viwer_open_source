# Bibliotecas de terceiros / Third-party libraries

O arquivo `g-code-viewer-v*.html` inclui as bibliotecas abaixo, convertidas para ES5 e compactadas pelo `build.js`.
O texto completo de cada licença vai junto, como comentário, dentro do próprio HTML, e também está na pasta [`licenses/`](licenses/).

The `g-code-viewer-v*.html` file embeds the libraries below, compiled to ES5 and compacted by `build.js`.
The full text of each license is included as a comment inside the HTML itself, and also in the [`licenses/`](licenses/) folder.
